# 字灵战记（Zi Ling War）

> **一部把汉字识字做成街机格斗的儿童游戏** —— 灵感来自《三国战记》式横版动作，把小学统编版语文教材的识字内容变成战斗机制。
> **字灵成长形态 = 大脑对它的记忆有多牢**（SRS 间隔重复驱动）。

面向小学 1–6 年级，提供 **浏览器即开即玩的 HTML5 版** 与 **Godot 桌面街机版（.exe）** 两个形态。能力始终来自「拼出字、学会字」——答错零代价，技能只能靠学会的字获得。

---

## 一、这是什么

不是识字卡片，是**能打的动作游戏**：

```
一关 = 一个教材单元（目标：学会单元内全部生字）
  ├─ 剧情：妖王抢走了这一关的字灵
  ├─ 小妖怪头顶带着部首偏旁，打死掉部件
  ├─ 捡齐两个部件 → 自动拼成这个字 → 🎉 恭喜组成「X」
  ├─ 每拼出一个字，就得到这个字的专属技能（带专属特效）
  │    「风」→ 狂风（旋风）  「火」→ 烈焰   「水」→ 洪流
  ├─ 妖王不断放出汉字招式（火球、水柱、雷击…都是汉字）
  └─ 把本关所有字都拼出来 → 全部技能打中妖王 → 通关
```

**两条红线（设计铁律，不许改）：**

1. **答错 / 捡错零代价。** 捡错只提示「不是这个字的部件」，被打死 800ms 原地满血复活。没有失败画面、没有排名。
2. **能力必须来自学会。** 技能只能靠拼出字获得。一旦可以靠签到 / 金币买技能，这游戏就废了。

## 二、数据规模

| 项目 | 数值 |
|---|---|
| 教材单元（关） | **61 个**（1 上 ~ 5 下，10 册） |
| 可玩幕 / 课 | **326 幕** |
| 单元生字 | **2985 个**（外加语文园地补充，字表共 **3017** 字） |
| 技能表 | **1844 个字**，14 种特效原型（cone/wave/spin/bolt/rain/vine/fall/blade/beam/burst/swarm/fist/dash/cloud） |
| 干扰项 | 按「容易混」分档（同韵母 / 前后鼻音 / 只差声调），绝不随机送分 |

数据全部来自教材「语文园地」收口切分 + 电子课本课号边界交叉核对，逐册 100% 吻合。**不编数据**：六年级因来源缺册而跳过。

## 三、两个形态

### ① HTML5 浏览器版（零依赖，手机可玩）

- `字灵战记.html` — **游戏本体**（单文件自包含，718 KB，含全部逻辑与样式，CSS/JS 内联）
- `字灵图鉴.html` — **识字图鉴原型 / 家长端**（单文件，含 SRS 复习、合成台、笔顺、家长看板）
- 纯 **Canvas 2D 软件 3D 渲染**（透视投影、画家排序、体素角色、粒子、浮字），**无 WebGL、无外部依赖、断网可玩**
- **WebAudio 实时合成 35 个音效**（零音频文件，加载 0 秒）
- 存档：`localStorage`（`ziling.war.save.v3`）

### ② Godot 桌面街机版（`.exe`）

- `godot/` — **Godot 4.4.1 工程**（1280×720，gl_compatibility，启动即全屏）
- 六位主角（金木水火土 + 隐藏雷「紫电」），三/四段连招、角色专属特招、街机式三段大招演出
- 2~4 大段 × 3 卡点关卡、Boss 狂暴、行商小驼补给站（花铜钱）、环境机关（落石/飞箭/喷火/水柱）、跳跃踩怪、冲刺闪避
- 全流程自动验证截图脚本（`tools/verify_*.gd`）

> 详细玩家操作见 [`操作说明.md`](操作说明.md)，动画与剪辑参数见 [`开发说明.md`](开发说明.md)。

## 五、怎么跑起来

**HTML5 版**：双击 `字灵战记.html`，或起个本地静态服务器：

```bash
python -m http.server 8765
# 浏览器打开 http://localhost:8765/字灵战记.html
```

**Godot 版**：用 Godot 4.4.1 打开 `godot/project.godot`，或直接运行导出的 `字灵战记.exe`。

## 六、开发与测试

**数据自检 & 流水线**（`tools/`）：

```bash
node tools/war-test.js      # 端到端游戏逻辑（61 单元 / 326 幕 / 拼字 / 技能 / 通关 / 续玩）
node tools/war-visual.js    # 画面像素客观验收（帧率 / 颜色数）
node tools/war-3d-check.js  # 3D 透视投影数学验证
node tools/gen-skills.js    # 按字生成技能表
```

**Godot 版已验证的坑**（详见 [`开发说明.md`](开发说明.md)）：

- `exclude_filter` 排除的路径代码里绝不能 `load()`（否则导出 exe 一进关就闪退）→ 已用 `_try_tex()` 判空 + 程序化兜底纹理
- 脚本二进制化会让运行时 `load("res://scripts/X.gd")` 失效 → **必须保持 `script_export_mode=0`**
- `.godot/imported` 缓存不一致 → 删 `.ctex` 后 `--headless --import` 重建
